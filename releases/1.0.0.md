# Guanaco 1.0.0

Released September 14, 2026.

Guanaco 1.0.0 introduced the first production release of the Guanaco Bitcoin
Cash decentralized exchange interface.

## Features

- Swap routing across compatible Guanaco and Cauldron liquidity pools.
- WalletConnect transaction approval and explicit broadcast confirmation.
- Slippage protection bound to the transaction approved by the user.
- Signed transaction review with network fees, liquidity-provider fees, asset
  identifiers, and copyable transaction data.
- Liquidity creation, migration, merge, and withdrawal workflows.
- Markets and My Liquidity views for discovering pools and managing positions.
- Support for multiple Guanaco fee tiers.
- GUA token information and swap entry points.

## Safety and reliability

- Pool inputs are validated before transaction approval and broadcast.
- Changed or spent transaction inputs trigger a refresh instead of reusing an
  obsolete transaction.
- Token metadata used for amounts is authenticated and untrusted metadata is
  handled conservatively.
- Public API endpoints, token icons, transaction fees, and WalletConnect flows
  include additional validation and security checks.

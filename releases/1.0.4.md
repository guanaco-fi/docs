# Guanaco 1.0.4

Released September 20, 2026.

Guanaco 1.0.4 improves wallet connection and keeps swap and liquidity actions
aligned with changing on-chain state.

## Improvements

- The WalletConnect pairing screen now focuses on compatible Bitcoin Cash
  wallets and better matches the connected-wallet panel.
- If a WalletConnect session ends unexpectedly, Guanaco clears the disconnected
  wallet's cached balances and controls instead of continuing to show them as
  connected.
- A visible swap quote updates when its selected liquidity pools change or
  become available. A transaction whose inputs have changed requires a fresh
  review and signature before it can be sent.
- Liquidity positions are reconciled when a spent pool is replaced, avoiding
  a temporary duplicate of the old and new positions.
- MINTY and BABYGUA token metadata is available in the trusted catalog.

This release does not change the underlying KTH or JS/WASM package versions.

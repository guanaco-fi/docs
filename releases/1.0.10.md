# Guanaco 1.0.10

Released September 23, 2026.

Guanaco 1.0.10 improves swap reliability when market liquidity changes rapidly.

## Improvements

- An obsolete signed quote is invalidated before it can be broadcast.
- After a successful swap or an input conflict, Guanaco prioritizes refreshing
  only the affected market.
- Stale pricing remains unavailable until replacement liquidity is confirmed.
- Pools confirmed as still live are restored when the conflict originated from
  another transaction input.
- If the affected market cannot be refreshed immediately, the interface
  provides an explicit retry action instead of quoting uncertain liquidity.

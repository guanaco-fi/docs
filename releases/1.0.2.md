# Guanaco 1.0.2

Released September 15, 2026.

Guanaco 1.0.2 improved liquidity-operation feedback, token metadata, and wallet
readiness handling.

## Improvements

- Liquidity balances clearly indicate when no wallet is connected.
- Partner token metadata is verified before it is used for value-changing
  operations.
- Migration, merge, and liquidity-deposit failures now surface specific wallet
  funding errors.
- Pool operations wait for connected-wallet funding data before transaction
  construction.
- Official social links and launch terminology were corrected.

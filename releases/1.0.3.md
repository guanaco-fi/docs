# Guanaco 1.0.3

Released September 17, 2026.

Guanaco 1.0.3 focuses on transaction safety and timely synchronization of
wallet balances and liquidity positions when on-chain state changes outside
Guanaco.

## Improvements

- Connected wallet balances now reconcile after relevant external on-chain
  transactions without requiring a WalletConnect reconnection.
- Spent liquidity positions are removed from My Liquidity and are prevented
  from returning through stale cached data.
- Swap and liquidity operations detect when a selected pool input changes,
  refresh the affected state, rebuild the transaction, and require a new
  approval when necessary.
- Transaction fee calculation now accounts for the final serialized
  transaction shape, including wallets that require multiple payment inputs.
- End-to-end coverage now exercises pool changes during swaps, migrations,
  merges, and withdrawals.

# Guanaco 1.0.12

Released September 23, 2026.

Guanaco 1.0.12 improves the Swap experience across desktop and mobile while
making transaction preparation more resilient when wallet inputs or market
liquidity change.

## Improvements

- Swap inputs now provide clearer focus feedback and keep amounts readable
  whether or not the field is active.
- Amounts entered by users remain ungrouped, large fiat values use compact
  notation, and invalid amounts are highlighted more clearly.
- Changing the destination token preserves the entered sell amount and
  recalculates the quote for the newly selected pair.
- Token amount entry respects each asset's supported size and precision.
- The mobile token selector closes with the browser Back action.
- WalletConnect QR codes remain centered on narrow screens.
- Mobile transaction confirmation no longer selects button text during a
  press-and-hold action.
- Swap shortcuts appear reliably when an amount field receives focus.
- Markets and Swap layouts no longer overflow horizontally on narrow screens.
- Quote updates and transaction-input warnings now use colors consistent with
  the Guanaco interface.

## Reliability

- Signed transactions are invalidated when their wallet or liquidity inputs
  become obsolete, requiring an updated quote before broadcast.
- Liquidity and wallet positions are refreshed after swaps, withdrawals, and
  migrations so the interface does not continue using stale state.
- Market data waits for a coherent liquidity snapshot before it is presented.

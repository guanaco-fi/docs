# Guanaco 1.0.14

Released October 9, 2026.

Guanaco 1.0.14 expands token access while making trust signals explicit and
improving wallet reliability.

## Improvements

- Any CashToken can now be selected and used at the user's discretion.
- Tokens without verified metadata display a clear warning in the token
  selector, while verified tokens remain visibly distinguished.
- FoldingCash (FLDCH) is now included as trusted token metadata.

## Reliability

- Wallet initialization can recover cleanly after an interrupted attempt.
- Transaction fee data remains synchronized while wallet inputs change.
- Wallet-opening behavior is more consistent across desktop and mobile.
